# mascot-demo：替换慕慕的名字和形象

把 Muvyo 后台右下角的慕慕换成橘猫「小橘」。只换名字和立绘，慕慕的能力、权限和对话方式都不变；不联网，也不运行任何逻辑，可以直接签名安装试用。

需要 Muvyo 3.11.1 或更新版本；旧版本认不出 `mascot` 能力，安装时会报清单不合规。

## 文件

| 文件 | 说明 |
|---|---|
| `manifest.json` | 在 `capabilities.mascot` 里声明名字和各动作的立绘 |
| `main.js` | 空入口：插件包必须有入口文件，形象插件不需要写函数 |
| `mascot-idle.png` 等 4 张 | 待机、眨眼、说话、挥手四个动作的立绘（程序绘制的示例图） |

示例只提供了 4 个动作，其余动作由 Muvyo 用相近的动作代替（见 [能力与接口 · mascot](../../docs/capabilities.md#mascot-慕慕形象)）。

## 试用

```sh
python3 mv_addon.py sign ./examples/mascot-demo -o .
```

带立绘的插件签名时需要 Pillow：`pip install cryptography Pillow`。

发布后在 Muvyo 里从插件仓库安装、启用，再到「设置中心 → 插件 → 慕慕 AI 助手」的「慕慕」区块，把「慕慕形象」选成「示例助手形象」并保存。右下角的形象和对话框里的名字会变成小橘，AI 回复时也自称小橘。停用或删除插件后自动回到官方慕慕。

## 换成你自己的形象

- 立绘建议 320×480、透明背景，人物脚底贴着画面下沿，各个动作用同一比例，切换时才不会跳动。
- 只想改名字：删掉 `frames`，只留 `name`，界面沿用官方立绘。
- 只想换立绘：删掉 `name`，名字仍是慕慕。
