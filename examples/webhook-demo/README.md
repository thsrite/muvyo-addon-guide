# Webhook 事件示例

演示 `webhookEvent(e)` 协议：记录媒体服务器发来的新入库、停止播放、标为已看事件，写进 Muvyo 日志，并在 `mv.storage` 里统计次数、保留最近几条。不联网，签名后就能装上试用。

**兼容性：需要支持 `webhook` 能力的 Muvyo 版本，旧版安装时会提示能力不受支持。**

## 试用

1. 复制本目录到自己的插件仓库 `src/<用户名>.watchlog`，把 manifest 的 `alice` 改成自己的作者命名空间，签名发布后在 Muvyo 安装。
2. 打开插件「设置」，打开 **接收 Webhook 事件**（安装后默认关），保存后启用插件。
3. 确认 Muvyo「设置 → Webhook 接收」已开启，并在「允许的事件类型」里包含 `library.new`、`playback.stop` 等事件；媒体服务器的 Webhook 地址指向 Muvyo。
4. 在 Emby 里点「发送测试通知」，或播放一段视频再停止，到 Muvyo 日志里能看到 `[插件] 「示例观看记录」……` 的记录。

## 写真实插件时

- 想把观看记录同步到别的网站，在 `permissions.domains` 声明那个网站，然后用 `mv.fetch` 推送；用户名、设备名属于用户的观看记录，只发给用户自己配置、确实需要的服务。
- 投递在后台进行：插件慢不会拖住媒体服务器，但单次最多 30 秒，插件忙或排队过多时这次事件直接丢弃，不补发。需要可靠同步时，在 `mv.storage` 里记下进度，配合定时任务补齐。
- 同一个条目可能连着来好几次事件（例如 Emby 删除会同时发 `library.deleted` 与深度删除），自己按 `item.id` 与时间去重。

完整字段见 [能力与接口](../../docs/capabilities.md#webhook-事件)。
