# 开发者协议与内容政策

领取作者证书、发布第三方插件，即表示你同意本页内容以及 [Muvyo 服务协议](https://muvyo.com/service-agreement.html#addons) 第 5.1 条。

## 你的责任

- 第三方插件由你独立开发、发布和维护，**不是 Muvyo 官方出品**。Muvyo 不审核、不背书你的插件；作者证书只说明插件出自哪个经 GitHub 账号核实的作者。
- 你对以你的证书签名发布的每个插件负责，包括它访问的网站、给出的内容和链接。
- 妥善保管签名凭据 `muvyo-signing.json`。私钥泄露时在 Muvyo「第三方插件 → 开发者」点「作废这张证书」，用 GitHub 账号确认后立即作废，再重新领取证书、重新签名发布。
- 领取证书时授权服务会记录你的 GitHub 账号编号与用户名、授权与设备信息，处理方式见 [Muvyo 隐私政策](https://muvyo.com/privacy.html#addons)。
- 不得冒用 Muvyo 或他人的名义，不得冒用他人的 GitHub 账号或命名空间。

## 禁止的插件

以下插件不得发布，发现后会停用插件、仓库或作者：

1. **侵犯他人权利**：提供、聚合或引导获取未经权利人授权的影视、音乐、图书等内容，或对接以此为主要用途的网站和服务。
2. **违法内容**：淫秽色情、赌博、违禁品等违反法律法规的内容。
3. **恶意行为**：窃取或外传用户的配置、令牌、搜索记录等数据，挖矿、刷量、攻击他人服务。
4. **规避他人的保护措施**：绕过网站的登录、付费、反爬、访问频率限制等技术措施。
5. **欺骗用户**：插件名称、说明与实际行为不符，或声称是官方插件。

## 代码与许可

- 你必须对插件代码拥有发布所需的权利。
- 移植他人代码时遵守原许可证。本指南的发布流程只上传加密签名产物，不提供上传源码或关闭加密的分支。若所用代码的许可义务与这种分发方式冲突，先停止发布，换用许可兼容的实现或取得相应授权；不能靠加密规避许可义务，也不要由 AI 根据许可证名称自行改成明文发布。
- 加密只是让仓库里的代码不再是明文，不代表可以发布你无权发布的代码。为核查投诉与安全问题，Muvyo 官方可以解密插件代码。

## 停用与申诉

- 对有证据的侵权投诉或安全问题，Muvyo 可以在所有客户端上停用某个插件（全部版本或某个安装包）、某个插件仓库、某个作者或某张证书；被停用的插件立即停止运行，7 天后从用户设备上自动删除。
- 停用时 Muvyo 会设法通知你（例如在你的插件仓库留言）。认为停用有误的，在 [第三方插件投诉页](https://l.muvyo.com/api/addon-complaint) 选「作者申诉」提交说明和证据，官方在 7 个工作日内答复。
- 你对以自己证书发布的插件给用户或第三方造成的损害承担责任。本政策适用中华人民共和国法律。
- 用户安装了哪些插件、插件的下载与使用次数，Muvyo 都不收集。

## 对插件的建议

- 需要用户各自的账号或密钥时，用 `secret` 类型的配置项让用户自己填，不要在代码里写你自己的密钥。
- 只声明真正需要访问的域名；能用用户自己部署的服务（`permissions.service`）就不要连第三方站点。
- 在 README 里写清插件做什么、访问哪些网站、需要用户提供什么。
