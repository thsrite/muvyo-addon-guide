# 示例内容源

内容源插件示例：连接你自己部署的内容服务，在 Vyo 里按虚拟库浏览和播放。

安装后在插件设置里填写「内容服务地址」（局域网里的服务直接填内网地址），再到「封面 & 虚拟库」新建虚拟库，来源选「自建服务（插件）」和这个插件。

权限：`permissions.service` 由管理员指定自建服务，`domains: []`；不需要 Muvyo 服务权限。演示分类、列表、搜索、详情和播放；教学接口使用自己的服务实现，示例地址为 `https://example.com`。

最低支持版本：Muvyo 3.13.0，manifest 已写 `min_mv_version: "3.13.0"`；更早的版本会拒绝安装。
