# 种子文件搜索示例

本示例对应新增种子下载能力的 Muvyo 开发代码，尚未发布正式支持版本；旧版不能安装使用。此处不填写未经验证的最低版本号。它仅使用当前宿主已有的 `mv.service`、`mv.config` 和 `mv.fetch`，不依赖账号信息、请求预算或完结剧集接口。

先配置并启用 BT 下载器，打开资源搜索接入（自动订阅还需打开订阅接入），并为目标网盘配置非根目录的保存目录。插件不需要 qBittorrent 的账号密码。

在插件设置中填写自建服务地址。教学服务提供两个接口：

- `POST /search` 接收 `{ "keyword": "示例", "limit": 20 }`，返回以下列表。可直接返回 `torrent`，也可先返回 `token`，由用户点击获取后换取下载描述。
- `POST /resolve` 接收 `{ "token": "item-2" }`，返回 `{ "torrent": { "url": "https://example.com/download/2", "headers": {} } }`。本示例获取免费，付费站点须另行声明并实现积分规则。

```json
{
  "list": [
    { "id": "1", "name": "示例资源", "torrent": {
      "url": "https://example.com/download/1",
      "headers": { "Cookie": "站点凭据", "Referer": "https://example.com/" }
    } },
    { "id": "2", "name": "待获取资源", "token": "item-2" }
  ]
}
```

下载地址和重定向目标都必须在插件获准的联网范围内。同服务地址可使用已授权的 `service`；其他域名需写入 `permissions.domains` 并由管理员确认。不要把种子下载成文本，也不要将二进制塞进搜索结果。

Muvyo 在内存中保存下载地址和请求头，网页只获得绑定用户、用途与有效期的凭据。凭据一小时后或服务重启后失效，需要重新搜索。已付费结果不会因此自动再买：在网页重新获取同一条目后，后续订阅可恢复使用新凭据，因此插件必须为同一资源保持稳定的 `id`。

Muvyo 校验最多 4 MiB 的 v1 / hybrid 种子，然后把原始字节上传给下载器，保留私有 tracker 信息；纯 v2 暂不支持。下载任务台账不保存站点密钥。种子与磁力按内容哈希去重，完成后沿用下载器插件的上传流程。点击搜索卡片的「查看下载任务」进入 BT 下载器插件，可查看进度、取消或删除任务；目标为 115 / 123 时也在这里管理。
