# 已入库标记搜索示例

资源搜索插件示例：对接自建搜索服务，拿到资源自身的 TMDB 身份后，用 `mv.library.lookup` 批量查媒体库，在结果的 `tags` 中添加「已入库」。不需要向插件提供 Muvyo 的媒体服务器账号。

## 使用

1. 复制本目录，按[示例说明](../README.md)把 `alice` 改成自己的作者命名空间，签名并发布到自己的插件仓库。
2. 使用支持 `permissions.muvyo` 的 Muvyo；安装时由管理员确认「查询媒体库」。**旧版 Muvyo 会拒绝安装声明了 `permissions.muvyo` 的插件**，代码中的降级不能绕过安装校验。
3. 在插件设置里填写「搜索服务地址」。内网服务需要明确允许访问；接口只是演示，按自己的服务修改 `main.js`。
4. 在资源搜索中选择本插件，用关键词查询。要看到真实的「已入库」，Muvyo 需要已配置且能查询到对应 TMDB 作品的媒体库。「测试运行环境」只检查代码载入，不执行媒体库查询。

只对接你有权使用的内容来源，见[开发者协议与内容政策](../../docs/policy.md)。新装插件默认不参与订阅搜索，示例也不执行转存。

## 自建服务约定

`POST /search` 接收 `{"keyword":"示例作品","limit":20}`，返回：

```json
{
  "items": [
    {
      "id": "sample-movie",
      "title": "星际穿越（字段格式示意）",
      "tmdb_id": 157336,
      "type": "movie",
      "tags": ["示例"],
      "link_type": "115",
      "share_link": "https://115.com/s/xxxx",
      "share_code": ""
    }
  ]
}
```

链接是占位示意，不是可用资源。实际服务应返回有权使用的真实分享；磁力条目改用 `"link_type":"magnet"` 和 `"magnets":["magnet:..."]`。没有可用链接的条目会被 Muvyo 丢弃。

`tmdb_id` 必须是资源自身核验过的数字整数，不能把查询条件的编号无条件贴给所有结果。电视剧还需返回 `"type":"tv"`、数字 `season` 和该资源所含的数字集号数组 `episodes`。缺少身份、编号为字符串或季号无效的结果仍展示，但跳过媒体库查询。

## 降级与标记口径

- 未获得 `library.lookup` 授权时，`mv.can` 返回 `false`，直接保留搜索结果。要手动验证这条路径，可在另一个教学副本移除 `permissions.muvyo` 后重新签名安装。
- 最多取 20 条，一次批量查询，按返回顺序对应回原结果；不逐条调用，不自动重试。
- 电影以 `exists` 为依据。电视剧只有资源集号明确、且全部出现在该季 `episodes` 中才标「已入库」，不能只看 Series 是否存在。这里的标签表示资源对应内容已有，不代表分辨率、版本相同。
- `complete` 表示查询完整性，不表示整季齐全；未确定命中且查询不完整时标「入库状态未查全」。已查到的内容即使部分服务器失败，仍可作正向标记。
- 未配媒体库、限流或读取异常时保留搜索结果，只记录不含查询内容的提示，不标「未入库」。媒体库辅助查询失败不代表资源搜索失败。

接口、用量与短时缓存详见[运行环境](../../docs/runtime.md#使用-muvyo-的服务)。
